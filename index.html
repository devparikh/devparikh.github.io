Work

Projects

Audio synthesis with WaveGAN

Generates multi-second audio waveforms without labels. WaveGAN adapts the DCGAN to audio by swapping 2D convolutions for 1D ones and dropping batch normalization, and it trains with the Wasserstein loss plus a gradient penalty (WGAN-GP) for more stable training. I wrote up the full implementation in an article on Medium.

  • WaveGAN
  • WGAN-GP
  • Unsupervised learning

Semantic segmentation for road scenes

A U-Net that labels every pixel in a self-driving car’s view, trained on the Cityscapes dataset. Data augmentation grew the 3,000 training and 500 test images to 23,800 and 4,000. Training used a custom Tversky loss, the Adam optimizer, a learning rate scheduler, ReduceLROnPlateau, and model checkpoints.

  • U-Net
  • Cityscapes
  • Tversky loss

Classic ML algorithms from scratch

K-Means clustering (with KMeans++ initialization and the elbow method) and Random Forest, built with only NumPy, Matplotlib, and Pandas. I tuned the Random Forest with 4-fold cross-validation across 36 configurations on a class-balanced Titanic dataset, reaching 95% average test accuracy over three runs.

  • K-Means
  • Random Forest
  • Cross-validation

Automatic image captioning

An attention-based encoder-decoder that writes captions for images. The encoder turns an image into feature maps, and an LSTM decoder with attention reads them to generate the caption word by word, using beam search to choose the best words. Trained on the Flickr8k dataset.

  • LSTM
  • Attention
  • Beam search

Object detection with YOLO

My implementation of the YOLO (You Only Look Once) detector using OpenCV and a pre-trained YOLOv3-tiny model, covering still images, video, and real-time detection.

  • YOLOv3-tiny
  • OpenCV
  • Real-time detection
